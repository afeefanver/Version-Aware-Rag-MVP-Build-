# Password Policy v2.0
**Effective Date:** July 1, 2025
**Supersedes:** v1.0
**Superseded By:** v3.0 (effective January 1, 2026)

## 1. Purpose
To establish standards for creating strong passwords to protect company systems and data from unauthorized access.

## 2. Scope
This policy applies to all employees, contractors, and third-party users with access to company systems.

## 3. Policy Requirements

### 3.1 Password Complexity
- Minimum length: 10 characters (increased from 8)
- Must contain at least one uppercase letter
- Must contain at least one lowercase letter
- Must contain at least one digit
- Must contain at least one special character (!@#$%^&* etc.)

### 3.2 Password Age
- Maximum password age: 60 days (reduced from 90 days)
- Passwords must be changed every 60 days
- Password history: Remember last 10 passwords (increased from 5)

### 3.3 Account Lockout
- Maximum failed login attempts: 3 (reduced from 5)
- Account lockout duration: 45 minutes (increased from 30)
- Automatic unlock after lockout period
- After 3 lockouts in 24 hours, account requires IT unlock

### 3.4 Password Usage
- Passwords must not be shared with anyone
- Passwords must not be written down or stored in plain text
- Use of password managers is required for all administrative accounts
- Passwords must not be reused within 1 year

## 4. Multi-Factor Authentication
- MFA is required for all remote access
- MFA is required for all administrative accounts
- MFA is encouraged for all user accounts

## 5. Enforcement
Violations of this policy may result in disciplinary action up to and including termination.

## 6. Revision History
- v1.0: Initial release (January 1, 2025)
- v2.0: Updated complexity and lockout requirements (July 1, 2025)
