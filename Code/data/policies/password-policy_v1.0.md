# Password Policy v1.0
**Effective Date:** January 1, 2025
**Supersedes:** None
**Superseded By:** v2.0 (effective July 1, 2025)

## 1. Purpose
To establish standards for creating strong passwords to protect company systems and data from unauthorized access.

## 2. Scope
This policy applies to all employees, contractors, and third-party users with access to company systems.

## 3. Policy Requirements

### 3.1 Password Complexity
- Minimum length: 8 characters
- Must contain at least one uppercase letter
- Must contain at least one lowercase letter
- Must contain at least one digit
- Special characters are optional but encouraged

### 3.2 Password Age
- Maximum password age: 90 days
- Passwords must be changed every 90 days
- Password history: Remember last 5 passwords

### 3.3 Account Lockout
- Maximum failed login attempts: 5
- Account lockout duration: 30 minutes
- Automatic unlock after lockout period

### 3.4 Password Usage
- Passwords must not be shared with anyone
- Passwords must not be written down or stored in plain text
- Use of password managers is encouraged but must be company-approved

## 4. Enforcement
Violations of this policy may result in disciplinary action up to and including termination.
